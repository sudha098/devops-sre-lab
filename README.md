# 🚀 DevOps–SRE Lab (40-Day Hands-On Journey)

## 📌 Overview

This repository documents a **40-day, hands-on DevOps → Senior SRE learning journey**, focused on **real-world production failures, debugging, and reliability engineering**, not just tool usage.

The goal of this lab is to build **incident-driven intuition**, **senior-level troubleshooting skills**, and **interview-ready explanations** aligned with how real systems fail in production.

> ❗ This is not a tutorial repository.
> ✔ This is a **failure-first, production-style SRE lab**.

---

## 🎯 Goals of This Repository

* Build **Senior DevOps / SRE thinking**
* Understand **why systems fail**, not just how to deploy them
* Practice **incident debugging, root cause analysis, and prevention**
* Prepare for **real production responsibilities**
* Be **interview-ready for Senior / Lead roles**

---

## 🧠 Learning Philosophy

This lab follows a **failure-driven approach**:

```
Break → Observe → Debug → Fix → Prevent → Explain
```

Each day simulates **real production incidents**:

* Pods crashing
* Services unreachable
* Config breaking apps
* Memory kills
* Bad deployments
* Container startup failures

---
